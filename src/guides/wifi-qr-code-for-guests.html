Every host has done it: reading a password out loud while a guest types it in, then reading it again because the second "l" was really a "1". A Wi-Fi QR code skips all of that.

How it works

A Wi-Fi QR code is a small block of text written in a standard format. It holds three things: the network name, the password, and the type of security. A typical one looks like this inside:

WIFI:T:WPA;S:Maple House;P:sunny-porch-42;;

When a phone camera sees that format, it shows a "Join network" prompt. One tap and the phone is connected.

Scanning on different phones

PhoneWhat guests do
iPhoneOpen the Camera app, point it at the code, tap the "Join" banner.
Android (most)Open the Camera app, or long-press the Wi-Fi icon in quick settings and choose the QR scanner.
Older phonesMay need a QR reader app. That's why the card also shows the network name and password in print.

Check these before printing

  • Exact network name. It must match letter for letter, including capitals and spaces. "Maple House" and "maple house" are different networks.
  • Password. Copy it from your router app or the sticker on the router instead of typing it from memory.
  • Security type. Most home routers use WPA or WPA2/WPA3. Pick "None" only for an open network with no password.
  • Hidden network. If your network doesn't show up in the list of networks, it's hidden. Tick the "hidden" box so phones know to look for it.
  • Test it. Scan the code with your own phone before you print ten copies. Forget the network on your phone first so the test is real.

Where to put the card

Guests usually ask for Wi-Fi within the first ten minutes. Put the card where they'll see it right away:

  • On the fridge, with a magnet
  • In a small frame on the entry table
  • On the nightstand in a guest room
  • On the cover of your welcome book

Printing two or four cards on one sheet lets you put one in each room. Cut along the dotted lines.

Show the password or not?

For guests, showing it in print is usually more helpful: laptops and older devices can't scan. If the card is somewhere visitors pass by, like a shop counter, you can hide the password and keep only the QR code. Remember that anyone who scans the code can still see the password on their phone.
