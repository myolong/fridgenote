Wi-Fi QR code card

Type your network name and password. Guests point their phone camera at the code and they're online. No more spelling out passwords.

The code is made in this browser. Your password is never uploaded.

How to use it

  1. Find your network name and password. They're often printed on a sticker on your router.
  2. Type them in and pick a layout. One big sign for a wall, two signs, or four small cards to cut out.
  3. Test it before you print. Point your own phone at the code on screen. If it offers to join your network, you're good.
  4. Print. Put one on the fridge, one by the guest bed, and one in the welcome book.

Tips

  • Use a guest network if your router has one. Guests get online without access to your printers, cameras, or shared files. Look for "Guest network" in your router's settings or app.
  • Network names are case-sensitive. "MapleHouse" and "maplehouse" are different networks. Copy the name exactly.
  • Security type: almost every home router today uses WPA/WPA2/WPA3. Pick that unless you know otherwise.

Questions

Do guests need an app to scan it?
Usually not. The built-in camera app on most iPhones and Android phones from the last several years recognizes Wi-Fi codes. The guest points the camera at the code and taps the prompt that appears.
Is my password sent anywhere?
No. The code is drawn by your browser, on your device. Nothing you type is uploaded to us or anyone else.
What if I change my Wi-Fi password?
The old card stops working. Make a new card with the new password and replace it.
Should I hide the password on the card?
If the card will sit somewhere public, you can uncheck "Show the password on the card." The QR code still works. Keep in mind that anyone who scans it can join your network.
My network is hidden. Will this work?
Yes. Check "My network is hidden" so phones know to look for it.
